# 脱单闺蜜 Skill · v1.2.3

菜菜出品。视频系列名为「挑战用 AI 脱单」。内部调用名与目录名保持 `cai-tuodan`；不设置未经本人确认的英文产品名。

想要怎样的相处，和别人从资料里读到怎样的自己，都值得慢慢说清楚。

「关于他」复用已有材料，聊清择偶与相处期待。「关于我」里的**闺蜜功能**从自己的截图或文字开始：帮朋友介绍时总能说出好多优点，轮到自己却只剩喜欢旅行、看电影？借闺蜜的眼睛，看看自己有多有意思，再写成真实、自然的简介与接话候选。适合成年人的自愿探索；不要求重做大问卷。

## 安装与试用

这是待安装包，不代表已经安装。解压后，将整个 `cai-tuodan` 文件夹复制到支持文件式 Skill 的宿主目录，例如 Codex 的 `~/.codex/skills/` 或 Claude Code 的 `~/.claude/skills/`。目标已有同名目录时先保留旧版，选择另一个测试目录，不直接替换。宿主加载方式以其当前说明为准。

也可以不安装，让助手读取本文件夹的 `SKILL.md`，然后说：「用脱单闺蜜 Skill，关于我，交友简介建议」。先发文字即可。首次可选 1 更合拍的人、2 更多机会、3 自己的目标；已有目标直接接。后续不重复介绍。

`SKILL.md` 是入口，`references/` 按需提供三项功能、归档、平台与证据说明。文字交流不依赖渲染脚本或额外环境。可选小卡随包提供渲染脚本：macOS PNG路径需要clang、AppKit和系统苹方字体；其他环境需要可靠HTML转PNG能力。缺渲染能力不影响文字交流，但不能声称已导出新PNG。

## 保存与隐私

本次不存、普通本地指定目录、OB 指定目录，由本人选择。私密底稿与可公开稿分开，包里不放用户档案。输入会由所使用的 AI 宿主处理；指定目录也可能被同步，不能视为完全离线保密。不要提供不必要的精确位置、账号或他人私信。

只提供本人审核的草稿，不登录、匹配、代发、上传私人画像或发布。没有结果保证，不打颜值或身价分。平台快照与研究局限见 references，真实图像能力尚未验证。

「关于我」完整交流内容按固定四段结构，从「一：先说说我眼中的你✨」开始，接三列表格小建议（主页位置／闺蜜的小小建议／为什么这样建议＋参考来源）与三种风格候选，选稿迭代后给平台字段成品。开头直接称呼本人；首次未知则问如何称呼。称呼只有在本人同意位置与范围后才存入包外唯一画像主档，未同意仅在当前对话使用。

正式改写前先选：想展示自己的哪一面，以及想认识什么样的人。回答并确认方向后默认给三种风格，本人明确只要一版时例外，也可明确授权先试一版。第三环节通用标题待确认，实际三版仍用既定标题；前两与最后标题不变。之后有新情况，随时回来“和闺蜜再聊聊💬”：大家总问什么、哪段聊得舒服、约见时间有没有合拍，都可以接着说。想记下来就选择本人指定目录，也可以不保存。

「见面之前」可直接从对方资料或简短描述开始，准备轻量赴约小抄，不要求先做其他模块。「和闺蜜再聊聊」按内容关联简介版本、同次见面记录，或直接一般交流。OB/本地布局与空模板见 [私人工作区模板](references/private-workspace-templates.md)，真实资料只存本人授权的包外目录。本人画像使用一个逻辑主档并保留版本，见面前后用同一 session_id 关联；不强制真名、不默认存完整截图。


本版直接用脱单闺蜜的口吻聊观察和建议，保留完整内容与原有固定标题。已知路径直接读，同批本地附件核对后复用，按功能、阶段与平台加载；相关才查证据。减少准备步骤不等于保证模型或附件服务的响应时间。
