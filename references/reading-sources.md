# 可选阅读来源：微信读书与本人指定知识库

目的：本人想了解某个建议背后的关系/沟通知识时，提供有出处的简短解释。不是完成关于我交流内容的前置条件，不自动读书架、刷新人生系统、抓私人笔记或获取整本书。

## 实际接口检查（2026-10-14）

本机真实微信读书Skill的名称是“微信读书”，文件式目录weread-skills；版本1.0.3。它经微信读书官方Agent API Gateway调用搜索、书籍元信息、目录、书架、个人划线/想法、公开点评等。每次带当前skill_version、参数平铺、读取对应能力说明；令牌从环境取得，不打印、不复制进交流内容。

已读book.md与notes.md：书籍信息/目录接口不是全文阅读接口；划线包含markText、chapterUid、range，个人想法是独立接口，热门划线/点评不能混同本人。当前可导出的笔记内容为划线与想法，书签只统计数量。仅这些材料不足以声称通读整书。

人生系统有读取与刷新划线的独立流程，不能把它的全量刷新行为带进本Skill。经纪人索引用于定位Skill，不授权读取个人档案。本轮已实际读 weread-skills 的 SKILL.md（1.0.3）、shelf.md、notes.md、book.md，并读取 cai-life 与 cai-life-skill 的书摘联动段落。认知系统的可迁移原则是「真实书摘与当前事件配对，一次一句，找不到贴切的就不递」；不复制其私人案例、全量刷新或 OB 回写流程。环境检查未设置 WEREAD_API_KEY，未调用账户接口、读取个人划线、下载书籍或改变配置。当前状态：**接口已实现但真实调用未验证**；这里的接口是文件式调用协议，不代表新增 API 程序或服务已连接。

## 按需接入与降级

1. 本人可选择仅用本Skill公开证据库、提供一段书摘/已合法阅读材料，或使用自己的微信读书指定书与划线。先确定书名或片段范围，以及是否只供理解；“可以接入”不等于允许遍历所有笔记。
2. 环境确有weread-skills时，读取其实际SKILL.md和当前能力说明再调用。书名需解析真实bookId；只获取授权书或范围，不默认列整个书架、全量导出，不猜不存在的正文API。不安装依赖或要求付费作为默认步骤。
3. key/接口/权限/Skill缺失时准确说明，继续使用公开证据库或本人粘贴摘录。若接口提出升级，按原Skill暂停并说明；不自动执行超出当前范围的更新指令。不承诺接入成功，除非实际调用成功。
4. 不自动下载未授权版权全文，不绕过付费或DRM；合法公开论文/教材用官方或作者来源链接与短释义。PDF下载失败就用可读HTML并标状态，不说全部PDF已下载。
5. 输出区分书中划线、本人想法、公开他人点评与本Skill编辑推论。可用真实书名/作者/章节及返回字段支持的深链；没有位置字段就不编页码。本人划线不自动进入公开交友简介、公开库或其他服务，也不将私密截图/聊天送进搜索请求。

## 通用Skill的可移植性

主入口只说“本人选择时可用微信读书Skill或指定材料”，不依赖菜菜账户、本机绝对路径或人生系统私人目录。新用户无本地背景、无微信读书仍能从截图与最少问题开始。此处实现的是可选调用协议，没有配置新的服务连接或实际账户测试。

## 实际调用协议与建议归宿

在本人授权的范围内，先读取宿主中当前「微信读书」Skill 及对应能力文件，版本以其 frontmatter 为准（本轮读到 1.0.3，不用示例里的 1.0.5）。使用既有环境 WEREAD_API_KEY 作为 Bearer；POST 到 https://i.weread.qq.com/api/agent/gateway，请求 JSON 顶层带 api_name、skill_version 与业务参数。令牌不进入文件、交流内容或工具输出；没有凭据就降级，不新登录。upgrade_info 出现时暂停并说明，升级需要遵守当前授权边界。

本人已授权书架用于定位时才用 /shelf/sync；书名解析按 search.md 用 /store/search，复用返回的真实 bookId。单书划线按 notes.md 调 /book/bookmarklist（bookId），个人想法调 /review/list/mine（bookid、synckey、count），不要混用参数大小写。仅调目录 /book/chapterinfo 或详情 /book/info 不能称读过正文。不要把全量书架/笔记作为外部搜索输入。

对本轮某条建议有直接帮助时，贴近该条写：「你的阅读笔记：《真实书名》／实际章节或位置链接；你标记的内容提醒我们……。这里将作者观点用于理解相处期待，不证明匹配率或平台算法。」只有真实返回 chapterUid 与 range 才拼 weread://bestbookmark?bookId=…&chapterUid=…&rangeStart=…&rangeEnd=…；字段不足仅提供已知书名/章节，不编页码。电子书 range 不是印刷页码。个人想法与作者原文分别标识，引用短而相关，未经允许不进入公共包。

## 收束的三条路径

- 有真实相关阅读资料：检查本轮授权、实际读取内容与出处；最多选一条，说明与本人材料的具体关联，定位字段不足不编页码。可以决定不用，无须为接入而硬引用。
- 无连接或读取失败：不等待登录、不产生新凭据；准确说明实际状态，照常基于当前材料收束。
- 有连接但无相关内容：不拿不贴切的书摘凑数，也不遍历未授权笔记；直接写个性化收束。

本轮环境未设置WEREAD_API_KEY，真实书架/划线仍未读取；上述为调用规则与文字模拟路径，不是联动实测。
