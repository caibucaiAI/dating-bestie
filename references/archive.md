# 可选归档与返场

选择只有本次不存、普通本地指定目录、OB 指定目录。已有授权按其范围执行，未提供实际目录只问路径；不能猜桌面或 Vault。无文件能力给待保存正文，明确未存。保存目录可能被同步，不声称绝不外传。

按本人选择保存的内容创建包外文件，默认最小摘要而非原截图/逐字聊天。原有两项功能的历史结构仍可使用，不自动迁移：

```text
本人指定目录/
  INDEX.md
  关于他/YYYYMMDD-代号-v01.md
  关于我/私密底稿/YYYYMMDD-代号-v01.md
  关于我/可公开版本/YYYYMMDD-代号-v01.md
```

只创建用到的功能目录。私密底稿包含目标、本人确认的事实、公开边界、已答问题与尚未知；可公开版本只含本人选择的公开文案，不附私人交流内容链接或原截图。INDEX 仅记日期、功能、代号、文件链接、下一步，不泄露私密事实。不能用一个整体文件代替隐私分离。本人只同意公开稿时，不擅自建私密底稿。

文件名用安全代号，不接收路径片段。已有文件新建 v02 或追加明确日期区块；不覆盖。保存前读目标确认并行变化、身份与授权；冲突不挑最像的一份。索引只追加缺失条目，已存在不重复。写后回读验证新内容和旧文保留，成功才报精确路径。

不存档：正常交付、无需文件与索引。可在对话内给两句接续摘要，不保证跨会话记忆。

返场：当前上下文先接；跨会话仅查本人指定目录的 INDEX 和对应最新文件，不扫全库。读取已答问题与上次想试的一处，再接最新反馈。改稿变化、真实交流变化与猜测分开，不从点赞变化推出因果。没有记录就诚实说明，可从上次停的那件事继续，不重问年龄职业。

## 称呼与唯一画像主档

第一次未知称呼只问如何称呼；不重复问已知背景。用户回答称呼不等于同意持久保存。需要以后记住时，说明用途并请其选择：本次不存／桌面本人指定目录／OB 本人指定目录／其他本人指定位置。明确同意文件位置及只保存称呼等最小范围后，才可把称呼写入包外唯一的本人画像逻辑主档（新建版本，保留历史）；不另建私人资料.md；未同意则仅当前对话使用，不保证跨会话记忆。不得在 SKILL.md、README、公共样例、安装目录或分发包记录用户称呼。

返场只读取本人指定且允许本轮复用的唯一画像主档；旧私人资料.md仅作兼容入口，存在时可按授权最小读取，不与主档并行维护，已有称呼直接用；没有可读资料就自然说明并问如何称呼，不扫描目录寻找姓名。本人拒绝、改称呼或撤回保存时尊重其范围；删除已有记录需明确指向对应文件与内容。更新前回读并保留其他内容，按既有归档不覆盖规则另存版本。存称呼与存完整交流内容分别授权，不附带保存截图或聊天。

## 和闺蜜再聊聊💬：内部版本记录

具体“用户回复什么→闺蜜怎样局部改”的虚构例见 [目标与回访对话](goal-and-followup-examples.md)：职业反复被问、约见时间不合拍、匹配多但关系方向不同。真实使用必须以本人实际回答代替案例职业/地点。

先按 [回聊路由](followup-routing.md) 区分简介反馈、见面后感受与一般聊天。以下版本记录仅适用于简介反馈。本人回来提供简介使用反馈时，先确认这次要解决的问题，不重做背景长问卷。可选择OB本人指定目录／其他指定本地目录／不保存；仅同意接入不等于同意写原OB，写入本人实际OB需明确路径和本次范围授权。未获准不创建数据、索引或定时任务。优先包外新建专属记录或明确追加区块，不覆盖旧档；照既有回读、版本与回读验证规则执行。

最小记录包含：原文、本人采用的改稿、日期/版本、当时想改善什么的假设、本人观察（反复被问什么、对话是否合拍、是否约得上、舒服与否；匹配量可选）、下一轮本人选择。将实际反馈、AI解释与尚未知分开；不把前后差异当文案导致的因果，不保证量增长，不用表现评定本人价值。旧版可保留或回退。

第三人去标识，私信和交流内容不进公共包；只保留反馈所需摘要，不自动索要整段聊天。不给他人建立追踪档案，不访问dating账户或代发。每轮只改与问题有关的一处或少量栏目，沿用已答事实和目标。

用户可见保存提示统一“要不要把这次聊到的记下来，下次我们接着聊？”。已有保存选择不重问，答应记下仍需确认实际路径与范围；没有授权不写文件。向本人呈现记录时用“上次用了哪版、这次哪里不一样、接下来想怎么改”，不把内部的假设/指标/因果字段照搬成聊天语气。


## 可选私人工作区适配（新增）

首次需要持久化时让本人选：OB 指定路径／普通本地目录／不保存，并确认这次具体保存什么（例如只存小抄，或小抄与见面后感受；本人画像另行确认）。路径和范围已有明确授权就沿用，不重复问；扩展范围再确认。未选择等同本次不保存，不建文件或索引，不影响交付。没有文件能力则交付正文并说未保存。

公共 Skill 只含通用规则、空模板和明确虚构的例子。真实本人画像、对象摘要、私聊、截图、称呼和实际私有路径只在包外本人指定的私有工作区，不能写入安装目录、SKILL.md 或公开包。不强制真实姓名，对象可用本人选的代号；默认不保存对方完整截图或原聊天。保存摘要前列清将写入的私密内容范围，获得确认再写。目录可能同步，不承诺绝不外传。

新工作区建议布局见 [私人工作区模板](private-workspace-templates.md)。本人画像只有一个逻辑主档，以不可覆盖的版本保留历史，INDEX 指向本人已确认的当前版本；不再并建一份私人资料.md造成两套本人事实。若旧私人资料.md 已存在，只按授权读取最小必要内容，本任务和后续普通使用都不自动迁移、覆盖、删除或批量移动旧笔记。

对象索引只记安全代号、唯一 person_id 和记录链接；不是追踪档案或硬标准评分表。每次见面使用唯一 session_id（日期加序号或随机ID，不能只用姓名或日期），同一对象多次见面分别记录，不同对象同名仍有不同ID。跨会话身份/次数不清先确认，不挑最新一条代替。只读取本人指定的索引及确认对应记录，授权路径外不扫描。文件名不含用户给的路径片段。

见面前新建 plan 文件，见面后在同一 session 目录新建 dated followup 文件，均带 person_id/session_id；通过链接关联，不覆盖计划。原来没有计划就标未保存，不补造。简介反馈写在 profile 对应版本的独立反馈记录中，不进见面记录。一般聊天只有本人要求保存才新建独立记录。

写入前回读目标文件/索引与授权，确认无并行变化；已有文件就新建版本，不覆盖内容。INDEX 只追加不重复条目，标当前确认版本时用追加说明，不重写旧条目；冲突先停相关写入并确认。写后回读，核对ID、链接和旧文保留后才报精确路径。偏好主档更新先展示候选变化，得到本人明确确认后新建版本；保存会后记录的授权不等于更新画像的授权。权限拒绝停止该路径写入并说明，不绕过、不擅换目录。
