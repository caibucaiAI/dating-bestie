# 交友资料：按场景适配指南

核查日期：2026-10-14。来源限公开官方网页；没有登录或复用任何个人账号。下文明确区分「官方已核实规格」「官方倡导」与「写作建议」。地区、语言、订阅、系统版本和灰度测试都可能改变可用字段；写入资料前以用户当前界面为准。未核实数字不作为硬限制。

## 通用工作方式

1. 先复用当前对话与本人授权背景中已明确的场景、关系意向、受众和公开范围；仅对影响交付的缺失、冲突或过时项追问，不把这份清单变成前置问卷。未知内容留空，绝不代填年龄、婚育计划、性取向、收入等。
2. 先找真实优势，再润色表达：从具体行动、生活细节、投入的兴趣和待人的方式里提炼。不能用虚构经历、财富、头衔或关系意愿包装人设。
3. 区分「资料里可以公开」与「仅供写作了解」。私下说过的事不自动获得公开许可；职业可写行业而非可定位的公司，地点可写城市而非住址或固定行程。是否披露身份、婚育、健康等由本人决定。
4. 看照片只评价清晰度、时效、是否容易认出本人、画面信息、真实活动和隐私风险；不评分颜值，不从外貌推断人格、收入、性取向或匹配价值。
5. 目标是让合适的人理解用户、找到真实话题。不得承诺算法加权、涨匹配率、某性别一定喜欢某种写法。偏好用尊重的正向描述，避免群体贬低和人口属性刻板印象。

## Hinge：三条回答承担不同信息

### 官方已核实
- 照片要求为 **4–6 张，依当地要求而定**，另需 **3 条 prompt 回答**；不能写死所有地区都要 6 张。[Hinge 资料编辑帮助，更新 2026-07-28](https://help.hinge.co/hc/en-us/articles/360011053094-How-do-I-edit-my-profile)
- 官方列出的字段包括身份与代词、工作/教育/语言、约会意向、年龄/身高/地点、家庭计划、宠物和生活习惯等；部分详情有「Visible on Profile」控制。字段存在不等于用户必须公开。[同上](https://help.hinge.co/hc/en-us/articles/360011053094-How-do-I-edit-my-profile)
- 同时显示 3 条文字回答；Photo Prompt 可选，Video Prompt 可选且可加 1 条，Prompt Poll 可选且为 1 个、含 3 个回答。具体题目从当前应用中选择。[Hinge Prompts 帮助，更新 2026-09-29](https://help.hinge.co/hc/en-us/articles/36311352171539-How-do-I-edit-my-Prompts)
- 官方资料刷新指南介绍 30 秒 Voice Prompt。它是内容选项，不是必须录满的要求。[Hinge 官方指南，2025-04-07](https://hinge.co/newsroom/profile-refresh-guide)
- **本次未从官方页面核实每条文字回答的字符上限**；常见的「150 字符」说法不写作已确认规则。最终按用户界面计数器检查，包括标点、空格和 emoji。

### 官方倡导与写作建议
官方鼓励具体回答、展示不同侧面，建议更新过时、遮脸和重复群体照；这类照片建议不是一律禁止的审核规则。[Hinge 官方指南](https://hinge.co/newsroom/profile-refresh-guide)

建议三条分别承担：
1. 日常生活：一个能想象的真实场景
2. 关系态度：用户确实在意的相处方式
3. 轻松话题：兴趣细节或容易回应的小问题

每条尽量只说一个重点，避免三个段落都重复工作、旅行或同一种笑话。照片与文字互补；选择当前样貌清楚的单人照，再补真实活动和生活场景。语音内容应像本人自然说话，不为显得有趣而模仿一个不属于自己的角色。

- 官方 Photo Tips 强调不同活动、环境和姿态的照片组合；该功能限部分市场，建议可自行采纳或忽略。[Tinder Photo Tips，更新 2026-08-26](https://www.help.tinder.com/hc/en-us/articles/48425605518861-Photo-Tips)

### 硬性内容边界
Tinder 公约禁止在公开资料展示电话号码、邮箱、社交账号等联系方式，也禁止裸露/性内容、虚假身份和商业拉客。不得未经同意上传他人照片或私信；平台面向 18 岁以上成年人。[Tinder Community Guidelines](https://policies.tinder.com/community-guidelines/intl/en/)

### 写作建议
Bio 可先写成少量短句：一个具体的生活特点、一个真实兴趣、一个清楚但不施压的关系意向或对话入口。已有字段承担的事实不必在 Bio 全部重抄；若界面有 Prompts，让它补充新信息。不要为获得关注暗示自己接受其实不想要的关系。

### 写作建议（不是平台格式要求）
- 标题：城市或生活阶段 + 真实交友意向，避免性别对立、羞辱他人、夸张资产标签或假悬念
- 正文：我现在怎样生活 → 两三个有细节的兴趣/特点 → 希望如何相处 → 适当的站内交流邀请
- 照片：选本人同意公开、能代表现在的生活照片；检查工牌、门牌、定位、车牌、聊天截图、他人和未成年人影像
- 私密程度：公开帖默认使用最低必要信息。收入、资产、医疗经历、前任故事、家庭成员资料和私人聊天不因“更完整”就加入
- 长度：以清楚、可读、不重复为目标，可先做短版和展开版；这是编辑选择，最终发布容量由当前界面验证
- 发布前单独审核文字、照片、地理标签、可见范围和 AI 标识。文稿完成不等于获准发布

## 朋友介绍／转发相亲简介：先限定谁能看，再写给谁看

这不是统一平台产品，**不存在可引用为通用标准的字段、照片数量或字符上限**。下面是场景化编辑建议，不是任何 App 的硬规则。

### 推荐结构
1. 本人同意分享的称呼、城市和生活阶段；年龄等只在明确愿意提供时加入
2. 当前工作/生活方式的简述；用事实说明可靠、好奇、体贴等优点，少堆抽象形容词
3. 两三个真实兴趣或相处细节，让收件人知道可以聊什么
4. 已确认的关系意向与重要相处偏好，避免把对方写成学历/资产/外貌的评分清单
5. 联系路径和转发边界：例如先由介绍人询问意愿，双方同意后再交换联系方式

### 两个独立版本
- **本人自述版**：只写本人认可的事实、感受与意向，不伪造朋友背书
- **朋友转介版草稿**：供朋友审阅；朋友与本人的关系、认识多久、见过哪些优点，必须由真实信息支持，不能编造“大家都说”“我保证很靠谱”

文案先做便于一屏阅读的短版，有需要再补充；照片数量由双方同意的传播范围和必要性决定。不能把给一个朋友看的详细资料自动变成群发版本；转发前明确收件人、内容和是否允许继续转发。隐私建议也适用于亲友转介：不轻易披露家庭/工作地址或可预测的固定日程。[Tinder 官方安全建议可作通用安全参考，非朋友介绍的产品规则](https://policies.tinder.com/community-resources/safety-tips/intl/en/)

## 交付前检查

- 每项事实能追溯到用户确认；模板中的示例没有被当成用户经历
- 输出显出用户真实优点，也保留其关系边界与个人说话方式
- 明确标注平台硬限制、官方建议、编辑建议和待核实项
- 当前字段/题目/计数器经用户提供的界面确认；没有为了查上限擅自使用被禁止的登录账号
- 照片中的其他人和私人信息已获得相应同意，无法确认则不放进待发布稿
- 公开、转发、发给朋友或修改线上资料是独立动作，按当次授权执行
- 不以外貌打分、群体刻板印象或算法保证评价成效
