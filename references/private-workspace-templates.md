# 私人工作区模板（包外可选）

下面是布局建议，不要求创建整棵树。OB 和普通本地目录使用相同 Markdown 结构，OB 可选双链，普通目录用相对 Markdown 链接。实际根路径和保存范围由本人指定；不将根路径回写公共 Skill。首次选择不保存则不创建任何文件。

```text
本人指定的私有根目录/
  INDEX.md
  本人画像/
    me-v001.md                 # 一个逻辑主档；更新另存 v002，索引追加当前版本
  对象/
    INDEX.md                  # person_id、代号、对应见面链接；不含真实姓名或私密履历
    p-example-a/
      2026-10-20-s01/
        plan.md
        followup-20261020T2100.md
      2026-10-28-s02/
        plan.md
  简介/
    profile-example-v001.md
    feedback-example-v001-20261021.md
  随聊/                       # 仅本人要求时创建
```

## 本人画像（按获准范围挑选字段）

```markdown
# 本人画像
profile_owner_id: me-example
version: 001
确认日期：示例日期
可用于：本人确认的用途
称呼：可不保存
已确认兴趣与相处偏好：
边界及不希望反复问的问题：
允许用于公开简介的内容：与私人理解范围分开
尚未确认的建议：不当本人事实，不自动写入已确认偏好
前版链接：如有
```

## 见面前计划

```markdown
# 赴约小抄
person_id: p-example-a
对象代号：虚构的小树
session_id: 20261020-s01-example
见面日期：未知可留未知
本人确认的保存范围：仅文字摘要，不保存截图
材料来源：本次对话的自述/转述，简短定位
对方明确自述：
本人观察或转述：
仍未知：
这次我想了解的／担心的：
可以顺着聊：话题与双方兴趣依据；本人愿分享的真实小故事
让我舒服一点：按需安排与边界
关联：见面后记录沿用本 session_id；尚未发生不填结果
```

## 见面后回聊

```markdown
# 回来聊聊
person_id: p-example-a
session_id: 20261020-s01-example
记录时间：示例时间
保存范围：本人确认的最小摘要
见面前计划：`plan.md`（保存后填写其实际链接）（没存则写未保存）
本人现在的感受：
具体事件与本人观察：
本人/AI的解释：分别标明，仍可能有其他解释
还不知道的：
本人想选的下一步：允许暂不决定
建议更新的本人偏好：候选、待确认；不因存此记录自动更新主档
```

## 简介反馈

用 profile_id、采用版本、实际使用文案链接、日期、本人观察、AI解释和尚未知、本人想改的一处关联；不默认分配 person_id/session_id。可公开稿与私密底稿继续按原归档规则分开，只授权公开稿就不附私人链接。

所有ID、日期和代号均为虚构示例。模板不收集评分、真实姓名、住址或完整截图；实际保存时删去未授权字段。
