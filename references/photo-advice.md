# 关于我：逐图建议

用户发本人照片或资料截图时，宿主支持多模态且确实看到图片即可分析，不要求先用文字描述。只有文件路径则先使用可用图像读取能力；宿主不能读图时明确说明，接受本人描述，不假装视觉审片。截图缺失/模糊只标缺口，不猜人物或OCR。

先沿用目标1更合拍且自己愿继续交流、2更多曝光匹配机会、3自由目标，以及已确认公开边界。年龄、性别、近期性不从长相判断。截图含他人头像、姓名、聊天、联系方式，先指出待去识别，不另存原图或发第三方服务。

## 每张照片给出的信息

用图1、图2等标号，按材料多少精简：

| 项目 | 具体写法 |
|---|---|
| 实际可见事实 | 单人/多人、人物是否能分辨、可见活动与背景、遮挡；不确定的物品或文字标不清楚 |
| 承担的信息 | 能否辨认本人、展示日常活动、真实兴趣、自然交流入口；单张可以只承担一种作用，不凑人格标签 |
| 表达与可读性 | 基于实际画面说明清晰度、曝光、主体位置、背景干扰、构图裁切；屏幕压缩不等于原照差 |
| 修改候选 | 具体建议保留、可选裁切、替换已有另一张或调整顺序，说明理由；裁切不能虚构人物经历、改变外貌或隐瞒关键事实 |
| 与其他照片关系 | 是否重复构图/活动，怎样增加愿意展示的生活侧面；首图选择服务目标与辨认，不做颜值排名 |
| 隐私与同意 | 门牌、工牌、票根、二维码、精确地点、旁人同意等；无法辨认的隐私只提示检查，不断言看见 |
| 待本人确认 | 拍摄时间、是否代表近期本人、活动是否真实日常、哪位是本人、是否愿公开；只问影响建议的缺口 |

通常先给最值得改的1–3处，再给候选顺序与理由。图少时允许只保留当前两张，不为了填满模板要求全身照、社交证明、笑容或消费补拍。若缺少能辨认本人/兴趣的信息，说明缺什么并建议从已有真实照片中选；本人也可以选择不展示。

文字与图相互核对：照片能呈现活动，不证明经常做、熟练、收入、人格或关系态度。新增caption只有已确认事实才能进入公开稿。用户说不像我就改，照片建议也尊重其舒服与选择。

不打颜值、吸引力或可约会总分，不从长相推断年龄、种族、收入、人格、健康或取向，不强迫迎合男性，不以曝光目标削弱底线，不保证匹配增长。分析只生成候选建议；改图、上传或发布不包含在此步骤。
